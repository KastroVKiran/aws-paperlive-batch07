Versioning
If you want to maintain multiple versions of the same file (file name) without overwriting
By default, the versioning is disabled for the bucket
	During the bucket creation
	After the bucket creation

States of a bucket;
	Unversioned bucket		- for which versioning is disabled
	Versioning enabled		- toogle bar will be visible	- for every object that is uploaded after versioning is enabled, we will get version id/number (alpha-numeric)
	Versioning suspended		- when you disable versioning for the bucket

=> S3 Replication
If you want to maintain the duplicate copies of the same file
It is mandatory to enable versioning for the bucket

Methods;
Cross region replication	(B1 - Mumbai ------> B2 - N.Virginia)	- Same account
Same region replication	(B1 - Mumbai ------> B2 - Mumbai)		- Same account
Cross account replication	B1 (any region) (Account 1)	------> B2 (any region) (Account 2) 

=> Storage Classes in S3
Frequently Accessed		- any data that you are accessing on a daily basis
Infrequently Accessed	- any data that you are accessing once in a month

To minimize the cost to the client
